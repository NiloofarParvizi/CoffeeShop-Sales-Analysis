# Coffee Shop Sales Analysis

This project analyzes coffee shop sales data to find useful business insights and understand sales patterns.

## Questions

1. Which coffee products have the highest sales?
2. What days and hours have the most sales?
3. How does revenue change over time?
4. Which coffee types generate the most revenue?

## Tools

- Python
- Pandas
- Matplotlib
- Seaborn
- SQL

## Project Structure

- `Data/` — Dataset
- `Python/` — Data analysis and visualization
- `SQL/` — SQL queries
- `Images/` — Analysis charts
